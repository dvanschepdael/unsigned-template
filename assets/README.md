`font.fix` is the preconverted shadowed Unscii FIX tileset from
`ngdevkit-examples/00-template/setup/ngdevkit-assets/rom/s1-shadow.bin`.
It contains the small and tall ASCII tiles expected by ngdevkit's text helpers.

The tileset is provided ready to use, so building this template does not need
ImageMagick or additional graphics conversion dependencies.
